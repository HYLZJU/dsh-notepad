# dsh-notepad

> 输入框工具栏里的全局记事本：多行笔记、内置待办、工作区归属、双击空白新建、一键插入提示词。

## 为什么

长会话里总会留下碎片：一个决定、一段代码、跨项目的待办。切出去开别的应用会打断思路。`dsh-notepad` 把一张淡黄色便签纸放进输入框工具栏，整个浏览器共用一份。

## 功能

- **全局单例** — 整个 Web 宿主只有一个记事本，不按会话分裂。关掉面板再打开，内容还在。
- **输入框原生入口** — 工具栏里的标签图标（`conversation.input.left`）。未打开时无背景、无边框，只保留图标；打开后才高亮。
- **可拖动、可缩放** — 拖标题栏移动；拖右边改宽、拖底边改高、拖右下角同时改宽高；位置和大小记在浏览器里。
- **多行自适应** — 每条笔记都是自动增高的编辑器：长段落正常换行，按真实行数长高，不会只显示一行。
- **内置待办** — 点任意笔记左侧的圆圈就把它变成待办，再点切换完成/未完成。状态由插件保存，**不需要手写 `- [ ]` 前缀**；插入到输入框时才按 `- [ ]` / `- [x]` 输出。
- **双击空白新建** — 双击记事本空白处即可新增一条并自动聚焦，也可以点标题栏的「+」。
- **工作区归属** — 每条记录在创建时保存它所属会话对应的**工作区标题**并显示在右侧标签；会话尚未归入工作区时显示「当前对话」。
- **插入 / 插入全部** — 把最后一条或全部内容写入当前草稿（`inputActions.insertText`，带 revision 守卫），只写输入框，不直接发送。
- **页内确认弹层** — 点「清空」后在记事本正中弹出「确定清空所有笔记吗？」和「取消 / 确定」两个按钮，不弹浏览器 `confirm`。
- **无宿主半** — 状态全在浏览器 `localStorage`，不写会话日志。

## 安装

本地开发目录：

```bash
dsh plugin --profile web add link:/path/to/dsh-notepad
```

从 GitHub 安装（固定 commit）：

```bash
dsh plugin --profile web add "github:HYLZJU/dsh-notepad#<commit>"
```

安装后重启 Web 宿主并刷新页面。

## 使用

1. 点输入框工具栏的标签图标打开记事本。
2. 标题栏 `+` 新建一条，或**双击空白处**新建（自动聚焦）；`×` 关闭。
3. 直接输入；编辑器随内容长高，长段落自动换行。
4. 点左侧圆圈把笔记变成待办，再点切换完成/未完成。
5. 底部「插入」写最后一条，「插入全部」写全部（换行分隔）。
6. 「清空」→ 面板中央确认框 →「确定」才清空。
7. 拖标题栏移动；拖右边 / 底边 / 右下角缩放。

### 待办

| 操作 | 结果 |
| --- | --- |
| 点普通笔记的圆圈 | 变成未完成待办 |
| 再点一次 | 标记为已完成 |
| 再点一次 | 回到未完成 |

插入时待办输出为 `- [ ] 内容` 或 `- [x] 内容`；普通笔记按原文输出。

## 结构

```
dsh-notepad/
├── package.json       # dsh.bundle.patch + dsh.client（platform: web）
├── cordis.patch.yml   # 插入宿主行（宿主半为空实现）
├── lib/
│   ├── index.js       # 宿主半：apply() {}
│   └── client.js      # 浏览器半：store、面板、槽位
├── README.md          # 中文
├── README_EN.md       # English
└── LICENSE
```

浏览器半是一个 ES module，通过 `window.__ModuleLoader__.load({ id: 'dsh-notepad', … })` 注册，只依赖宿主的 `react` / `react-dom` 共享模块。样式在 `apply()` 时注入一次（所以工具栏按钮和面板共用同一套主题）。

## 已知限制

- **按浏览器隔离** — 数据在 `localStorage`，不同浏览器/设备不同步。
- **模型看不到** — 除非你点「插入」，否则记事本内容不会进入会话。
- **固定浮层** — 面板是 `position: fixed` 的 portal，浮在输入框上方，不参与对话流布局。
- **旧数据迁移** — 曾经手写 `- [ ]` 前缀的笔记会在读取时自动拆成状态并剥掉前缀。
- **link 安装是开发用法** — `link:` 指向源码目录；长期使用建议复制安装或发布包。

## 开发

没有构建步骤：直接改 `lib/client.js`，重启宿主或重新安装后刷新页面。提交前可先 `node --check lib/client.js`。
